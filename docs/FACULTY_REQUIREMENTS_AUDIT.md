## Phase 9 artifact verification and validation results

It confirmed six methods, exactly 888 unique questions per method, 276 paper clusters, identical query sets and configuration compatibility. Every gold ID matched the QASPER validation annotation; every retrieved ID was a unique paragraph in its source paper. Recall@1/5, MRR@5 and nDCG@5 were recomputed from saved rankings and agree with stored means. The 2,000-replicate paper-cluster intervals and paired comparisons were checked against those rows. The artifact marks `test_split_accessed: false`; no held-out query data or inference was used.

## Remaining compliance limits

- The four faculty-specified neural retrievers have real validation results. E5/GTE are older encoder generations; do not claim that they are the newest available SOTA systems.
- E5 is the quality-first local default only when its pinned weights are staged; otherwise the UI safely falls back to BM25. MiniLM is the measured speed-oriented alternative.
- Public deployment is not verified, but the planned faculty demo is localhost; no cloud setup is required for that plan. Docker Engine is unavailable and no hosted HTTPS flow is claimed.
- Accessibility evidence is automated Chromium testing at desktop and 375/390 CSS-pixel sizes. Other browsers/physical devices and manual assistive-technology review remain outstanding.
- The root project source license remains undecided. Phase 7/8/9/10 files remain uncommitted; the published baseline is `e700a81`.
