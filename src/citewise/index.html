Dataset and methodology

Preprocessing. Empty paragraphs are removed, whitespace is collapsed, evidence is whitespace-normalized and case-folded, and matching gold text maps to stable original paragraph IDs. Figure/table-only and unmatched evidence are reported rather than converted into text.

Recall@k. For gold paragraph set G, Recall@k = |G ∩ top-k| / |G|. Recall@1 is computed from the first saved validation candidate.

MRR@5. Reciprocal rank of the first relevant paragraph within five results, or zero when none appears.

nDCG@5. Binary-relevance discounted gain divided by the ideal gain; relevant passages ranked earlier receive more credit.

Evaluation unit. Metrics are macro-averaged over scorable questions. Bootstrap resampling keeps questions from a paper together, using 2,000 replicates and seed 42.

Neural model handling. The checkpoint table shows each neural model ID, pinned revision, query/document formatting and measured status. Validation results apply only to the QASPER validation split.

Encoder differences. MiniLM is the compact 6-layer encoder. BGE adds a retrieval instruction to the query and uses CLS pooling; E5 uses distinct query: and passage: prefixes with mean pooling; GTE uses general-purpose mean-pooled text embeddings. Different training objectives, text formatting and input truncation change the similarity geometry, so rankings differ; these comparisons do not isolate one cause.
